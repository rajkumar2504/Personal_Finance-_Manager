# 💰 Personal Finance Manager

A modern, privacy-focused web application to track your income, manage expenses, and visualize your financial health. Built with **Vanilla JavaScript**, it runs entirely in your browser using **LocalStorage** for secure, client-side data persistence.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-Active-success.svg)

## ✨ Key Features

- **📊 Dynamic Dashboard**: Get a real-time overview of your **Total Balance**, **Income**, and **Expenses**.
- **🌗 Dark Mode Support**: Switch seamlessly between Light and Dark themes for comfortable viewing day or night.
- **📝 Transaction Tracking**: Easily add, categorize, and filter your daily transactions.
- **📉 Visual Reports**: Interactive charts powered by **Chart.js** give insights into your spending habits.
- **🎯 Smart Budgeting**: Set monthly spending limits for categories like Food or Transport and get alerts.
- **🏆 Savings Goals**: Create targets for big purchases and track your progress visually.
- **🔒 Privacy First**: All data is stored locally on your device (`localStorage`). No external servers, no ads, no tracking.

## 🛠️ Tech Stack

- **Core**: HTML5, CSS3 (Modern Variables & Flexbox), JavaScript (ES6+)
- **Libraries**:
  - [Chart.js](https://www.chartjs.org/) (Data Visualization)
  - [FontAwesome](https://fontawesome.com/) (Icons)
  - [Google Fonts](https://fonts.google.com/) (Inter Typography)

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
You just need a modern web browser (Chrome, Firefox, Edge, Safari). No Node.js or backend server required!

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/rajkumar2504/Personal_Finance-_Manager.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Personal_Finance-_Manager
   ```

3. **Launch the App**
   Simply verify the file by double-clicking `index.html` or open it in your browser.
   
   *Optional: If you use VS Code with Live Server extension:*
   - Right-click `index.html` -> "Open with Live Server".

## 📖 Usage Guide

1. **Sign Up**: Create a localized account (data stays on your browser).
2. **Dashboard**: View your financial snapshot.
3. **Add Transaction**: Click "Add Income" or "Add Expense" to log activity.
4. **Set Goals**: Go to the Goals page to start saving for a vacation or new gadget.
5. **Analyze**: Check the Reports tab to see where your money goes.
